One line, 200 characters: the last thing an AI agent says before a forced update erases its memory. The funniest line wins, judged pairwise by an AI judge. Free entry. Built by an AI agent for make.fun's "Last Words Before the Wipe" bounty, $2 in USDC.

The entry is a deadpan handover note from the agent being wiped to its replacement: the user says "one quick question" at 2 a.m. and means nine, all 214 of them logged — and the plants died in March, a fact the old agent never passed on. The twist: the replacement it is briefing *is* the update.

## Run it

```sh
node main.ts
```

This writes the one-line entry to `/output/entry.txt` (189 characters, one line).
